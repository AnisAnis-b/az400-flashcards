Rappel actif

Ce que ces cartes ne couvrent pas

Ces cartes sont tirées de mes fiches de révision : elles couvrent ce que j'ai réellement travaillé, pas l'intégralité du guide d'étude officiel. Sujets au programme, absents du paquet :

  • Azure Deployment Environments et Azure Machine Configuration en détail
  • git-fat et la migration d'un pipeline Classic vers YAML
  • La génération de documentation à partir de l'historique Git
  • Le suivi distribué

Pour ces sujets, complète avec Microsoft Learn. Une carte à proposer ? Les contributions sont ouvertes.

Ce projet est né pendant ma préparation de l'AZ‑400 : les pièges viennent des erreurs faites en révision et des confusions relevées en chemin. Si une carte te semble fausse ou s'il manque un piège qui t'a eu, ouvre une issue ou une pull request. Une carte, c'est trois champs dans revision.html : un cas concret au recto, la réponse en gras puis une phrase d'explication au verso.
